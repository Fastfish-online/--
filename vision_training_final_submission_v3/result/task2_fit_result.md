# Task 2 - 合成旋转视频参数拟合

## 1. 输入视频
- 文件：`resources/task_2.mp4`
- 实际分辨率：682 × 512
- 实际帧率：30 FPS
- 实际帧数：720
- 时长：24.00 s
- 有效样本：720，帧范围：0–719
- 旋转中心：(341.0, 256.0)。原任务给定 960×720 与中心 (480,360)，本素材实际为等比例缩放后的 682×512，因此使用实际画面中心。

## 2. 识别与角度计算
采用 HSV 阈值提取青色目标：H∈[80,110]，S∈[120,255]，V∈[80,255]；取最大外部连通区域质心作为目标中心。按照讲义定义 `θwrapped = atan2(cy-y, x-cx)`，再进行相位连续的角度展开。

## 3. 拟合模型
讲义给定角速度模型：`ω(t) = b + A sin(Ωt + φ)`。直接对展开角度使用其积分形式：

`θ(t) = θ0 + b t + A/Ω [cos(φ) - cos(Ωt + φ)]`

使用带约束的非线性最小二乘（Levenberg-Marquardt）拟合 `θ0, b, A, Ω, φ`，并采用多组频率/相位初值以避免落入局部极小值。约束：A>0、b>A、Ω>0；φ统一到 [-π,π)。

## 4. 参数结果

| 参数 | 数值 | 单位 |
|---|---:|---|
| θ0 | 0.350113 | rad |
| b | 1.350008 | rad/s |
| A | 0.550110 | rad/s |
| Ω | 1.650018 | rad/s |
| φ | 0.701248 | rad |

速度变化周期 `T = 2π/Ω = 3.807950 s`。

## 5. 误差与结果文件
- 角度 RMSE：**0.002427 rad**
- 角速度诊断 RMSE：**0.022480 rad/s**（中心差分 + 21 点移动平均，用于角速度曲线展示）
- `fit_comparison.png`：观测角度与拟合曲线
- `angular_velocity.png`：估计角速度与模型曲线
- `residuals.png`：角度残差
- `tracking_overlay.mp4`：逐帧跟踪可视化
- `observations.csv`：逐帧坐标、角度、拟合值与残差

## 6. 结果分析
所有 720 帧均检测到青色目标，轨迹连续，没有因颜色分割失败而产生缺失样本。拟合残差保持在较小范围内，说明给定的正弦角速度模型能够较好描述该合成旋转视频。
